# solarstuds

simple react app for testing stuff locally.

## how to run

1. make sure node.js is installed.
2. open a terminal in this folder.
3. run `npm install` if packages are not installed yet.
4. run `npm run dev`.
5. open the local link that vite shows in the terminal.

## if you want to check the build

run `npm run build`.

## notes

- `dev.cmd` can also be used on windows if you want.
- if something looks broken, try deleting `node_modules` and run `npm install` again.
